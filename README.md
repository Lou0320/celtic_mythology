# Celtic Mythology – guided research project

Run the website:

```
python3 js/server.py
```

Then open http://localhost:8000

| File | Role |
|---|---|
| `index.html` | The page: 3D canvas, log in card, the two book pages |
| `index.css` | Blur, log in card, page fade-in |
| `js/page.js` | Log in → intro → show the pages |
| `js/scene.js` | 3D scene: desk, lamps, book, camera zoom |
| `js/server.py` | Tiny local web server |
